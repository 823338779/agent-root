# Nova Agent 平台复刻文档索引

## 文档目标

本目录联合 Nova 产品仓、API/WS 黑盒测试仓 `nova_auto_test`、浏览器端到端测试仓 `nova_ui_e2e`，描述如何在没有原仓库、没有原会话上下文的情况下重新实现业务效果等价的 Agent 平台。

当前状态：75 篇文档已全部完成并经过独立审查与修订。结论以静态代码、配置和测试资产分析为主；本轮未运行应用、构建或自动化测试，因此文中只有明确标注的运行证据才可视为运行验证。

| 来源 | 主要证据 | 使用限制 |

| Nova | 产品实现、API、领域数据、插件、运行时和前端 | 静态存在不等于已运行验证 |
