# 桌面界面约定

## 使用场景

开发者在 Windows 桌面联调多个进程，主要任务是确认运行状态、查看错误日志和按需重启。采用 Operate 模式和已确认的服务列表＋日志面板，不引入弹窗导航。

## 视觉与交互

- 浅灰工作区 `#f3f5f8`、白色内容面板、深蓝灰正文 `#19283b`，主操作蓝 `#2458b5`。
- Microsoft YaHei UI 显示中文；Consolas 只用于运行日志。标题 21 pt，正文 10 pt，服务行高 44。
- 表格使用文字区分健康、失败和源码变更；绿色、红色、棕色提供辅助提示，不能仅通过颜色传递信息。
- 服务表保留五行；窗口最小 960×640，默认 1180×780，详情和日志随窗口扩展。日志支持横纵滚动和复制。
- 前端端口带打开标记，悬停为手型，单击在默认浏览器打开；选中后的“打开页面”按钮提供键盘可达入口。
- 后台每轮扫描结束后更新服务状态。操作中禁用冲突按钮，停止仍可取消构建。空日志说明下一步操作，错误直接显示在详情或日志。
- 源码变化不弹窗、不自动重启；列表标记与变更文件页签是唯一提醒入口。

## 核验

真实 Tk 交互测试覆盖启动按钮、内联变更、浏览器 URL 分发和关闭时进程清理。此原生 Tk 界面不包含 Web CSS 或浏览器断点。
